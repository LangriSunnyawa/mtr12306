════════════════════════════════════════
一、这是什么
════════════════════════════════════════

一个建立在 MTR（Minecraft Transit Railway）之上的网页式铁路客票系统。

玩家在浏览器里像逛 12306 一样查车次、选坐席、挑座位、付钱出票；
服务器里摆放检票闸机，闸机只放行「本站正在检票车次」的持票旅客 —— 有票抬杆放行并显示乘坐区间，无票原地拦下并说明原因。

换句话说：MTR 负责把车开起来，这个模组负责让人「买票 — 检票 — 上车 — 出站」这一整套客运流程跑起来。

二、功能一览
════════════════════════════════════════

■ 网页购票（12306 风格）

· 选出发站 / 到达站 / 日期 → 查询车次 → 选择坐席（直接显示票价与余票）→ 选车厢 → 在座位图上点座位（可留空自动分配）→ 扣款出票
· 我的车票 / 退票：未检票且未发车可退票，票款原路退回
· 检票动态：今日发车与「检票中 / 已强制停检」状态，10 秒自动刷新
· 出票包含：票号、车次、乘车日期、区间、坐席、座位号、检票口、票价

■ 坐席 / 车厢 / 餐车

· 支持二等座、一等座、商务座、城际（自由席）、无座
· 城际为不对号入座：出票不分配座位号，票面显示「XX车 自由席」，按定员限量
· 餐车可以单独标注：在任意坐席里填「餐车车厢号」，餐车会出现在座位图中但不可选座、不参与排座
· 每节车厢可设置排数与座位排列（如 A B C|D F，竖线为过道），座位号按「排 + 列字母」生成，例如 12F

■ 票价：统一 0.1 元/公里

· 停靠站填写累计里程，票价 = 里程差 × 0.1 元/公里 × 坐席倍率（farePerKm 可改）
· 扣费直接走 MTR 自带的 fares 钱包（计分板 mtr_balance），与 MTR 售票机、票价闸机共用同一余额
· 余额不足直接拒票并提示差额；退票自动退款；管理员可用 /mtr12306 balance <玩家> <金额> 充值

■ 车次：批量开行 + 在线修改

· 批量开行：填号段（前缀 + 起止号 + 步长 + 位数）、停站模板（区间运行分钟 / 停站分钟 / 区间里程）、车底与坐席、首班时刻 + 发车间隔，一次生成整批车次并自动推算时刻表与累计里程
　例：G1101~G1105，06:00 首发、间隔 20 分钟，自动得到 06:00 / 06:20 / 06:40 …
· 车次列表点「修改」即可载入既有配置，改完保存覆盖；支持「每天开行」或指定日期、跨日车次（天偏移字段）

■ 检票闸机（模型沿用 MTR）

· 模型几何直接沿用 MTR 的 ticket barrier（MIT 许可），只重做了贴图，可以和 MTR 自带闸机混排
· 四种闸机，放在独立创造物品栏「MTR-12306 检票闸机」里：

　进站闸机：校验车票 → 绿箭头放行并核销车票；无票红箭头推回并提示原因
　出站闸机：只放行从站台侧走出，并记录车票「已出闸」
　双向闸机：进站查票；出站要求「今日已有已检票车票」
　换乘闸机：一次通过同时完成「上一段出闸」+「接续车次检票」，两段区间分别显示

· 配置面板物品：拿「闸机配置面板」右键闸机（需 OP）才会打开配置菜单，可设置所属检票口与通行模式
· 检票口限定在闸机所在 MTR 车站：模组会读 MTR 的车站区域，配置菜单只列出该车站的检票口；不在任何车站内时列表为空并提示

■ 后台与账号

· 管理后台（/admin）：车站（一键导入全部 MTR 车站）、检票口、车次 / 坐席 / 车厢、闸机绑定、检票控制（手动开检 / 强制停检）、检票校验、票价钱包、车票总览
· 网页注册：昵称 + Minecraft 名称 + 密码注册（加盐多轮哈希），之后用昵称 + 密码登录；车票会记录下单账号；也保留「游戏内 /ticket login 取验证码」登录方式

════════════════════════════════════════
四、安装与开服
════════════════════════════════════════

1. 把 mtr12306-b1.0.0-hotfix1.jar 放进客户端与服务端的 mods 文件夹；
2. 装好 fabric-api 与 MTR 4.0.5+；
3. 启动服务器，会自动生成 config/mtr12306.json；
4. 看启动日志，会打印网页地址：

　[MTR-12306] 网页购票系统已启动：http://localhost:8123/
　[MTR-12306] 局域网访问地址：http://192.168.x.x:8123/

5. 浏览器打开 http://服务器IP:8123/ 购票，/admin 进管理后台（默认密码 mtr12306，请务必修改）。

常用配置（config/mtr12306.json）：

　{
　　"webPort": 8123,
　　"adminPassword": "改成你自己的密码",
　　"timezone": "Asia/Shanghai",
　　"farePerKm": 0.1,
　　"boardingOpenMinutes": 15,
　　"lateGraceMinutes": 2,
　　"transferWindowMinutes": 30,
　　"requirePayment": true,
　　"requirePlayerAuth": true
　}


════════════════════════════════════════
五、五分钟上手
════════════════════════════════════════

1. 在 MTR 里划好车站（车站工具 / MTR 面板），记下车站名；
2. 后台「车站管理」→ 一键导入全部 MTR 车站（保持同名，闸机才能绑到该站的检票口）；
3. 「检票口管理」→ 新建 A1（可指定负责站台，留空 = 全部）；
4. 「车次管理」→ 填车次号、停靠站（站台 / 到达 / 发车 / 天偏移 / 累计里程）、坐席与车厢（含餐车、城际自由席）→ 保存；
　 或者用「批量开行」按号段一次生成一整批；
5. 游戏内 /give @s mtr12306:ticket_gate_entry（或从创造物品栏取），在站厅摆一排，放置时面向站台一侧；
6. 拿「闸机配置面板」右键闸机 → 选检票口 + 模式 → 保存；
7. 玩家网页注册 / 登录 → 买票 → 到检票时间走过闸机 → 抬杆 + 屏幕显示「乘坐区间」；
8. 管理员可用 /mtr12306 boarding open <车次> <车站ID> 15 立即开检 15 分钟演示。

════════════════════════════════════════
七、已知限制 / 注意事项
════════════════════════════════════════

· 闸机没有「栏杆」：MTR 的闸机模型本身只有机柜，所以拦截是靠推回实现（和 MTR 一致）。介意的话可以在闸机间加玻璃板做视觉隔断。
· 闸机必须在 MTR 车站范围内才能选检票口；本系统车站要与 MTR 车站同名（用「一键导入」最省事）。
· 后台「闸机管理」的下拉框是管理员通道，允许跨站改绑；玩家侧 / 游戏内配置严格按车站过滤。
· 网页默认监听 0.0.0.0:8123 且是 HTTP 明文：公网部署请改端口 / 防火墙，或套一层 TLS 反向代理，并一定修改默认管理密码。
· 换乘闸机依赖两个条件：①上一段车票已检票进站且未出闸；②本站有已购接续车票且在检票窗口或 transferWindowMinutes（默认 30 分钟）内。
